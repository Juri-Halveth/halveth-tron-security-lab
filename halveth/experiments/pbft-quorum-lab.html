TRON context stays separate

The current TRON developer documentation describes DPoS with 27 active Super Representatives. It describes solidification when at least 19 distinct active SRs have each produced a block at that height or above. That rule is based on produced-chain progress; this lab's set-intersection model is not a TRON consensus switch.

Source code can contain PBFT message types without proving that the live network is running this abstract PBFT model. The diagram models arithmetic only. It sends no requests and has no node, wallet, or RPC connection.
